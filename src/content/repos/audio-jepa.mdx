Audio-JEPA is the implementation artifact behind the corresponding publication. It keeps the pretraining recipe, model configuration, and evaluation path close to the paper so the experimental setup is easier to inspect.

The code lives in a focused repository so the pretraining recipe and benchmark path can be inspected without unrelated experiments in the way.

## What is inside

- Audio-JEPA model and pretraining configuration.
- Evaluation hooks for generic audio embedding benchmarks.
- Reproducible training entrypoints for the paper experiments.
